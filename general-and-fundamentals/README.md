# General & Fundamentals

Core technical knowledge that supports practical work across cybersecurity disciplines.

## Focus areas

- Networking fundamentals, protocols, and packet analysis
- Linux and Windows administration
- Shell scripting and automation
- Identity, authentication, and access control
- Cryptography and security principles
- Web technologies and common security concepts
- Security tooling and technical documentation

## Learning approach

Prioritize practical exercises that build transferable skills. Record the problem, environment, commands or tools used, observations, and lessons learned. Keep explanations focused on why a technique or concept matters in real security work.

Foundational topics already completed should not be listed as pending work. New entries should represent actual exercises or meaningful independent study.

Use the [write-up template](../templates/WRITEUP-TEMPLATE.md) where a structured report is useful.
