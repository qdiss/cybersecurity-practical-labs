# Challenge Catalogue

An index of practical challenges and investigations to work through. This catalogue is a planning document, not a record of completed work.

**Status definitions**

- **Planned** — selected for future practice; not yet completed.
- **In Progress** — currently being worked on.
- **Completed** — completed and documented in this repository.
- **On Hold** — intentionally paused.

Difficulty and estimated time are deliberately left unspecified until they can be verified from the platform or the actual challenge page. Availability and room content can change.

## Adding an entry

Before adding a challenge:

1. Link to its official platform page.
2. Verify its current title and availability.
3. Add difficulty or estimated time only when the platform provides reliable information.
4. Keep the status accurate.
5. Link a completed write-up only after it has been published.

**Note:** Linux Fundamentals has already been completed and is intentionally excluded from the pending list. No flags, answers, credentials, or spoilers belong in this catalogue.
