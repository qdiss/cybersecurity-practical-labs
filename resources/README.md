# Resources

A curated index of official documentation and free learning resources. Prefer primary sources and maintained documentation.

## Training platforms

- [TryHackMe](https://tryhackme.com/) — guided rooms and practical cybersecurity challenges.
- [CyberDefenders](https://cyberdefenders.org/) — blue-team labs and investigation challenges.
- [LetsDefend](https://letsdefend.io/) — SOC analyst and incident-response practice.
- [Blue Team Labs Online](https://blueteamlabs.online/) — defensive-security investigations.
- [OverTheWire](https://overthewire.org/wargames/) — hands-on exercises for Linux and security fundamentals.
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) — free web application security training.

## Official technical documentation

- [MITRE ATT&CK](https://attack.mitre.org/) — knowledge base of adversary tactics and techniques.
- [NIST Cybersecurity](https://www.nist.gov/cybersecurity) — cybersecurity guidance, frameworks, and publications.
- [OWASP](https://owasp.org/) — application security projects and guidance.
- [Sigma](https://sigmahq.io/) — generic signature format for SIEM detection rules.
- [Splunk Documentation](https://docs.splunk.com/) — search, monitoring, and platform documentation.
- [Wireshark Documentation](https://www.wireshark.org/docs/) — network protocol analyzer documentation.
- [Zeek Documentation](https://docs.zeek.org/) — network security monitoring platform documentation.
- [Microsoft Learn: Security](https://learn.microsoft.com/en-us/security/) — Microsoft security documentation.

## Linux and networking

- [Linux man-pages](https://man7.org/linux/man-pages/) — Linux command and system-call reference.
- [The Linux Documentation Project](https://tldp.org/) — Linux documentation and guides.
- [Cisco Networking Basics](https://www.netacad.com/) — networking learning material.

## How resources are selected

Resources should be relevant, trustworthy, and preferably free to access. Link to official documentation where possible. Add a short note explaining why a resource is useful rather than collecting links without context.
